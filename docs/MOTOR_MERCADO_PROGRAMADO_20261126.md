# MACROLIGA · Activación del mercado piloto (26/11/2026)
Autorización del propietario: comenzar las pujas ahora y realizar una primera compra nocturna del Equipo Malo. Hora 01:00 o 02:00 indistinta; se conserva 01:00 (reglas originales), publicación/apertura 06:00, Europe/Madrid.
- Migración 015 protege el programador interno, usa la lista blanca, mantiene el rol externo NOLOGIN, evita ejecuciones simultáneas y reutiliza las operaciones idempotentes existentes. El cron se ejecuta cada 5 min, con cierre efectivo al instante de la hora límite del servidor; las protecciones de seguridad/RLS se conservan.
- Arranque excepcional: adelanta el único borrador sin pujas ni traspasos a la ventana actual; se inicia la temporada piloto para habilitar el ejecutor. Solo en ese ciclo el Equipo Malo adquiere los activos no adjudicados de menos de 750.000 €. Los ganadores humanos tienen prioridad; los restantes siguen el arrastre habitual. En ciclos posteriores, el Equipo Malo adquiere tras el segundo día.
- Los 16 equipos conservan plantillas y saldos iniciales. No se programan puntuaciones, no se habilitan ventas entre managers y no se modifica Comunio Laviana.
- Prueba SQL local: 26 migraciones, umbral estricto, adjudicación a manager, salida de inactivos, registros contables, aislamiento, no duplicados, ciclo nuevo abierto y normalización al segundo día.
- Para pausar el programador sin borrar datos: `select cron.alter_job(job_id := (select jobid from cron.job where jobname='macroliga_piloto_mercado_diario'), active := false);`. Detener también la admisión de pujas requiere una decisión explícita: desactivar cron no altera por sí solo el ciclo abierto.
